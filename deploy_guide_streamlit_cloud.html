ふるりーどSPEED 管理画面 デプロイ手順

Streamlit Community Cloud（無料）／ 想定所要時間: 10〜15分 ／ 2026-05-05

事前確認

1
ローカルの値を確認
2分

ターミナルで以下を実行し、メモ帳などに値を控える。

grep ANTHROPIC_API_KEY ~/projects/claude_taira/CDO_tech/ai_agents/furulead_speed_bot/.env

続いて、管理画面ログイン用の ADMIN_PASS を生成。

openssl rand -base64 18
メモする値（5つ）
① ANTHROPIC_API_KEY（grepで確認した sk-ant-... の値）
② ADMIN_PASS（opensslで生成した値）
③〜⑤は固定値なので下のStep 4ブロックをそのまま使ってOK
2
Streamlit Cloud にログイン
1分

https://share.streamlit.io/ を開き、 「Sign in with GitHub」 から bbloverskobe24-eng アカウントでログイン。

初回はGitHubの権限承認画面が出るので「Authorize」を押す。

3
新規アプリを作成
2分

右上 「Create app」 または 「New app」 をクリック。「Deploy a public app from GitHub」を選択。

入力欄設定値
Repositorybbloverskobe24-eng/furulead-roas
Branchmain
Main file pathstreamlit_app.py
App URL（任意）furulead-roas など分かりやすい名前
※ Repository欄でリポが見つからない場合
Streamlit Cloud画面右上のアカウントアイコン → 「Workspace settings」 → 「GitHub」 → 「Edit GitHub permissions」 から、対象リポへのアクセスを許可。
4
Advanced settings で Secrets を設定
3分

「Advanced settings」を開く。

  • Python version: 3.11
  • Secrets: 下のテンプレを貼り付け、①と②を実値に書き換える
ANTHROPIC_API_KEY = "ここにStep1①の値（sk-ant-...）"
ANTHROPIC_MODEL = "claude-haiku-4-5-20251001"
ADMIN_PASS = "ここにStep1②の値"
CHATWORK_API_TOKEN = "ローカル.envの CHATWORK_API_TOKEN を貼り付け"
CHATWORK_ROOM_ID = "326433964"
⚠️ シークレットの取扱い
Secrets欄に入力した値はStreamlit Cloudが暗号化して保管します。コードリポジトリには絶対にコミットしない（.gitignoreで .streamlit/secrets.toml 除外済）。
5
Deploy 実行
3〜5分

下部の 「Deploy」 ボタンを押す。ビルドログがリアルタイム表示される。

ビルド成功すると、URL（例: https://furulead-roas.streamlit.app）が発行される。

初回ビルドで ModuleNotFoundError が出た場合
requirements.txt がリポジトリのルートにあるかStreamlit Cloud側のキャッシュ設定で「Reboot app」して再試行。
6
動作確認
3分
最終チェック

発行されたURLを開き、以下を確認。

  • パスワード入力画面 → ADMIN_PASS でログイン
  • サイドバーまたはタブ 「🎯 ROAS分析」 を選択
  • 事業者情報を仮で入力 → 「分析実行」
  • レーダーチャート / 売上予測 / 推奨プランが表示
  • PDFダウンロードボタンが動く
